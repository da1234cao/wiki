# 前言

这部小说，我2024年看了一半。当时，感觉太长了，不大想看了。

几年，捡起来，无聊的时候打发时间。

# 书评

[神秘复苏这本小说讲了什么故事，为啥评价那么高？ - 知乎](https://www.zhihu.com/question/473399649)

总体上来说，这部小说还不错。

- 虽然全文是鬼故事，但是情节并不恐怖。真有恐怖剧情，我还不一定敢看，影响睡眠。另外，找寻鬼的杀人规律，会引入一些探索情节。有点像柯南。
- 这部小说，比鬼灭之刃要好看的多。鬼灭之刃的打斗场景挺炫，但是故事情节太单薄了。

但是，有些地方太啰嗦，即太水了。

- 比如引入国外的驭鬼者，没啥必要。

# 写书评的今天

今天是 2025/12/29，北京朝阳，晴。

请了三天年假，和元旦连在以前。早上，很早很早就醒了，然后把这本小说翻看完了。
