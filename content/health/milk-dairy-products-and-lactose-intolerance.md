## 前言

下班后嘴馋，可能会喝啤酒或者原味可乐。这两个虽然好喝，但是都不太健康，一个含有酒精，一个含有糖。无糖可口可乐，感觉没有原味可乐好喝。

我打算替换掉它们，所以看上了牛奶。喝牛奶不是为了营养，那点营养吃点鸡蛋和钙片就行了，关键是过过嘴瘾。但是，我的肠胃不太好，也乳糖不耐受，所以喝不了那种量大便宜的桶装奶。

零乳糖牛奶比普通的牛奶贵些。从性价比的角度出发，或许可以试试豆奶。也不知道，不加糖的豆奶好不好喝。搞点尝尝。

## 一杯牛奶里有什么

牛奶不是单一的白色液体，更像一个稳定的混合体系。大致可以这样看：

```text
牛奶
├── 水：主要背景
├── 溶在水里的东西：乳糖、矿物质、部分维生素、乳清蛋白
├── 悬浮的小颗粒：酪蛋白胶粒
└── 分散的脂肪小球：乳脂
```

乳糖是牛奶里的糖，主要待在水相中；乳清蛋白也主要溶在水里。酪蛋白则组成很小的胶粒，悬浮在水中。乳脂不是直接溶进水里，而是以许多脂肪小球分散在其中。

乳清是牛奶凝固、酪蛋白被拿走之后，剩下的那部分液体。它含有许多水、乳糖、乳清蛋白和矿物质。

市售牛奶一般经过均质处理，脂肪小球被打得很小，于是能较均匀地留在牛奶里，不会很快浮出一层厚奶油。

## 从牛奶里分出不同产品

```text
完整牛奶
├── 加乳糖酶 → 无乳糖牛奶
├── 保留乳脂为主   → 黄油
└── 酪蛋白 + 乳脂 → 奶酪
```

### 普通牛奶

它保留了水、乳糖、乳蛋白和乳脂。对于乳糖不耐受的人，问题不在于牛奶“不健康”，而在于小肠乳糖酶不够，乳糖没有被充分分解。剩余乳糖进入大肠后被细菌发酵，就可能出现腹胀、排气、腹痛或腹泻。

耐受程度很看个人。有人少量随餐喝没事，有人一小杯就不舒服；不需要因为有乳糖不耐受，就自动把所有奶制品从生活中删掉。

### 无乳糖牛奶

无乳糖牛奶通常不是把乳糖过滤掉，而是在普通牛奶中加入乳糖酶，把乳糖分解成葡萄糖和半乳糖。它仍保留牛奶的蛋白质、脂肪和钙等营养，味道有时会略甜一些。

这也是它和植物奶最根本的区别：它依然是牛奶，仍含牛奶蛋白。乳糖不耐受一般可以喝；牛奶蛋白过敏的人则不能因为它写着“无乳糖”就放心喝。

### 黄油

黄油的起点是奶油，也就是乳脂比例更高的部分。不断搅拌后，原本分散的脂肪小球相互聚合，形成黄油；排出去的液体带走了大部分水、乳糖和蛋白质。

所以黄油主要是乳脂，乳糖通常很少，但不是保证绝对为零。多数乳糖不耐受者少量使用一般问题不大，不过它也不是补钙、补蛋白的奶制品，日常更应该把它当调味脂肪来用。(我虽然比较喜欢咸鲜味，但是加了黄油的手抓饼，奶香味确实很足)

### 奶酪

做奶酪时，凝乳酶或酸会让酪蛋白聚成固体的凝乳块，随后排出乳清。因为大量乳糖原本待在水相和乳清中，所以会被带走不少；发酵菌还会继续消耗一部分乳糖。

因此，熟成时间长、质地硬、含水少的奶酪，往往比普通牛奶容易耐受。

奶酪并不只是“牛奶的固体版”。它把蛋白质和脂肪浓缩了，也常常带来更多盐和饱和脂肪；乳糖低并不代表可以不受量地吃。

## 豆奶

豆奶或豆浆来自黄豆和水。它有大豆蛋白和大豆脂肪，但没有乳糖、酪蛋白或乳清蛋白，所以通常适合乳糖不耐受者。

|          | 牛奶                     | 豆奶／豆浆                       |
| -------- | ------------------------ | -------------------------------- |
| 来源     | 动物乳                   | 黄豆加水研磨制成                 |
| 蛋白质   | 酪蛋白和乳清蛋白         | 大豆蛋白                         |
| 乳糖     | 有                       | 没有                             |
| 脂肪特点 | 全脂牛奶含较多饱和脂肪   | 以不饱和脂肪为主                 |
| 钙       | 天然含量较高             | 未强化产品通常较低               |
| 需要留意 | 乳糖不耐受、牛奶蛋白过敏 | 大豆过敏、添加糖、是否强化营养素 |

如果用豆奶替代牛奶，比较值得找的是：无糖或低糖、有一定蛋白质，并且标注添加钙和维生素 D 的产品。

## 乳糖不耐受时，怎么选更省心

最好的策略通常不是一刀切，而是找到自己的耐受量。

| 情况                     | 更合适的选择                                                                |
| ------------------------ | --------------------------------------------------------------------------- |
| 想保留接近普通牛奶的营养 | 无乳糖牛奶、无乳糖酸奶                                                      |
| 想吃乳制品但减少乳糖     | 少量原味发酵酸奶、熟成硬奶酪                                                |
| 只需要少量烹饪或涂抹     | 黄油可少量用，但它主要是脂肪                                                |
| 想不用奶制品             | 无糖、强化钙和维生素 D 的豆奶；也可以从钙盐豆腐、带骨鱼、深绿色蔬菜等补充钙 |
| 容易踩雷的场景           | 普通牛奶、奶茶、奶昔、冰淇淋、炼乳、奶油甜点，以及含奶粉或乳清的加工食品    |

普通牛奶不一定要完全戒掉。可以从小份量、随正餐一起吃开始，观察症状；若需要，也可以考虑乳糖酶产品。

## 关于豆奶粉和奶粉

成人喝的即溶豆奶粉和普通奶粉通常可以用常温饮用水冲，只是更容易结块、溶得慢。用约 35--50°C 的温水通常更好冲；若产品添加益生菌或对水温有要求，按包装说明来。

婴儿配方奶粉是例外。粉末并非无菌食品，不能沿用成人奶粉的随意冲法，应严格按罐身说明、当地卫生建议和儿科医嘱准备，尤其是低月龄、早产或免疫功能较弱的婴儿。
