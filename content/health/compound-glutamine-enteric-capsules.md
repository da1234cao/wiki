# 前言

最近，我的下结肠有些不适。问问豆包，找点药吃吃。

豆包给出的答复是：谷氨酰胺 + 双歧杆菌三联片 + 布拉氏酵母菌。

然后，打开京东的医保买药，搞点尝尝。

布拉氏酵母菌，以前吃过，它是散装的，需要用水冲服。它的价格有点贵，而且味道也难喝，换成酪酸梭菌。

但是，注意这两种益生菌的效果是不同的。布拉氏酵母菌，直接压制有害菌（大肠杆菌、沙门氏菌、痢疾类），缓解腹痛、水样泻、胀气，不修复肠黏膜。酪酸梭菌，产大量丁酸（肠壁细胞的口粮），补黏膜。

谷氨酰胺是人体含量最多的非必需氨基酸，肠道细胞最优先、最爱用的能量物质，有利于修复肠道粘膜屏障。

谷氨酰胺买的是复方谷氨酰胺肠溶胶囊(Compound Glutamine Entersoluble Capsules)。这个药，买回来，我才注意它包含中药成分。我这个人，深恶痛绝的厌恶中药。我不希望我的医保个人账户，有一分钱花在中药上。当时，买回来了，还能咋整，吃呗。

总的来说，谷氨酰胺 + 益生菌的组合，还是很好的。没有副作用，让肠胃也变的舒适些。

但是，既然碰到了，我还是要查询下这个复方谷氨酰胺肠溶胶囊。

# 复方谷氨酰胺肠溶胶囊

药物不是普通的食物。必然有：监管信息、临床实验的有效性和安全性证明。

## 药物的监管信息

可以在[国家药品监督管理局](https://www.nmpa.gov.cn/)上，查询到这款药物。

它的国药准字是 H51023598。

- H：代表 化学药品
- 51：代表 四川省（生产单位所在地代码）
- 02：代表 2002 年 首次批准（最新批准日期为 2024-10-21）
- 3598：为当年的 批准顺序号

挺好。这款药物是化学药，不是中成药。走的是化学药物的监管审批流程。

只要不是中成药，我还是在一定程度上，相信我们国家的药品监督的。

另外，这款药物，[国家药品监督管理局药品审评中心(CENTER FOR DRUG EVALUATION,CDE)](https://www.cde.org.cn/) 检索不到。**因为它属于特殊历史审批品种，是“地方标准升国家标准“**。

## 药物的基本信息

可以在[中国医药信息查询平台](https://www.dayi.org.cn/drug/1025517.html)上，查询到这款药物的基本信息。

本品为复方制剂，其组分为L-谷氨酰胺、人参、甘草（蜜炙）、白术、茯苓。

本品用于各种原因所致的急、慢性肠道疾病和肠道功能紊乱，如肠易激综合征、非感染性腹泻、肿瘤治疗引起的肠道功能紊乱和放化疗性肠炎；亦可促进创伤或术后肠道功能的恢复。

1、急性毒性试验，用一级小白鼠，一日内连续灌胃2次，用药剂量相当于人日用量的489倍，连续观察7天，均未发现异常和1例动物死亡。

2、长期毒性试验，SD大鼠每日灌胃给药，用药剂量相当于人日用量的99倍，每周7天，连续9周，各项检查指标均无异常发现。

## 临床试验

即使，这款药物是特殊历史时期的审批品种，在 CDE 中查询不到。

但是二十多年过去，一个化学药物，必然有临床实验。最起码，应该证明，安全性 + 有效性。否则，无法堵住悠悠之口，必然要受到质疑的。

可以在[中国临床试验注册中心](https://www.chictr.org.cn/showproj.html?proj=64903)中，搜索到这个临床实验：“**多中心、随机、双盲、安慰剂平行对照撤药试验评价复方谷氨酰胺肠溶胶囊治疗腹泻型肠易激综合征（IBS-D）的有效性和安全性**”。这个名字，我可太喜欢了。

> 多中心（Multi-center）
> 
> 不是一家医院做，而是多家医院同时做。
> 
> 
> 
> 目的：避免单中心偏差、地域差异、医生习惯差异，让结果更可靠、更普适。
> 
> 
> 
> 
> 
> 随机（Randomized）患者完全随机分到两组：
> 
> 治疗组：吃复方谷氨酰胺肠溶胶囊
> 
> 
> 
> 对照组：吃安慰剂
> 
> 
> 
> 谁也不能挑选分组，避免人为偏倚。
> 
> 
> 
> 
> 
> 双盲（Double-blind）
> 
> 患者不知道自己吃的是药还是安慰剂
> 
> 
> 
> 医生 / 研究者也不知道
> 
> 
> 
> 只有统计师 / 系统知道分组→ 彻底避免心理作用、主观判断偏差，保证结果客观。
> 
> 
> 
> 
> 
> 安慰剂平行对照（Placebo parallel control）
> 
> 安慰剂：外观、气味、大小完全一样，但没有有效成分。
> 
> 
> 
> 平行对照：两组同时开始、同时结束、同步观察，不交叉、不轮换。→ 用来排除 “自愈”“心理安慰效果”，真正判断药物本身是否有效。
> 
> 
> 
> 
> 
> 撤药试验（Withdrawal trial / 减量 / 停药试验）
> 
> 先让所有患者统一服药一段时间，达到症状缓解
> 
> 
> 
> 然后随机分成两组：一组继续服药。一组停药（或换成安慰剂）。观察：哪一组更容易复发、症状反弹。目的不是看 “吃药有没有效”，而是看：停药后会不会复发 → 证明药物有真正维持疗效的作用，不是临时缓解。
> 
> 
> 
> 
> 
> 研究对象：腹泻型肠易激综合征（IBS‑D）：
> 
> 反复腹痛、腹胀
> 
> 
> 
> 大便稀、水样、次数多
> 
> 
> 
> 无器质性病变（肠镜正常）
> 
> 
> 
> 
> 
> 研究药物：复方谷氨酰胺肠溶胶囊
> 
> 谷氨酰胺 + 中药成分
> 
> 
> 
> 保护肠黏膜、调节肠道功能、改善腹泻、腹痛
> 
> 
> 
> 
> 
> 研究目的
> 
> 有效性：是否减少腹痛、腹泻、频率、改善整体症状
> 
> 
> 
> 安全性：不良反应、耐受性、是否安全
> 
> 
> 
> 
> 
> 用最简单一句话总结 ： 这是一项多家医院参与、患者随机分组、医患都不知道吃的是药还是安慰剂、在症状缓解后进行停药观察的严格试验，用来证明复方谷氨酰胺肠溶胶囊对 IBS‑D 是否有效。

# 不再复购复方谷氨酰胺肠溶胶囊

我厌恶中药，不购买任何包含中药成分的药物。所以，不再购买该药物。除非这个药物有更详细的实验证明。

复方谷氨酰胺肠溶胶囊，每粒成分：谷氨酰胺 120mg，人参 50mg，甘草(蜜炙)50mg，白术 50mg，茯苓 50mg，辅料为玉米淀粉、硬脂酸镁。
