## quartz 的使用

详间官方文档：[Welcome to Quartz 5](https://quartz.jzhao.xyz/)

### 安装

官方文档：[安装](https://quartz.jzhao.xyz/getting-started/installation)

首先是，克隆它的官方模板。

然后是安装依赖。

```
npm i
```

初始化网站。

```
npx quartz create
```
