# 前言

有一天我死了，我希望我的数字遗产，可以再存在十年。

目前，我使用wordpress，记录文档内容。但是，wordpress 属于是有状态的服务。它必须间隔打理打理，要不然，站点可能就挂了。

我希望找一个 saas ，来记录我的文档内容。

找了一圈，我选择了 `confluence cloud `：[https://da1234cao.atlassian.net/wiki/spaces/share/](https://da1234cao.atlassian.net/wiki/spaces/share/)

但是，`confluence cloud` 的 SEO 非常糟糕。最终，我决定放弃使用它，继续使用现在的 wordpress。

这里，记录下这次折腾的过程。

# 文档软件需要满足的条件

| 指标 | 备注 |
| --- | --- |
| 可以使用 markdown 编辑 | 写起文档来，比较方便 |
| 保存图片和附件 | 图床有挂掉的风向 |
| 公网访问和SEO(Search Engine Optimization) | 虽然写了也没人看，哈哈 |
| 使用的人多 | 使用过程中不容易出问题，出问题也好找答案 |
| 背后的公司，必须足够的大，可以跨越经济周期 | 别因为公司倒闭，导致服务没了 |
| saas 优于 自建的服务 | 花点钱能解决的事情，就不要自己折腾了 |
| 向公司使用的文档软件靠拢 | 多人使用的场景更复杂，功能更多。 |
| 优先选择国外的服务 | - 国内有言论控制，可能写个翻墙的文档都不行  
- 国内的网站还得备案。  
- 国内的 saas 及时目前可以提供 公网访问和 SEO，说不定哪天因为不可抗力就被关了。 |
| 可选：支持多种语言 | 一份内容，可以便捷的切换成不同的语言，以应对国内外的访问。 |
| 可选：支持版本控制 | 这里的版本控制，不是单个文档的历史版本。而是值，对于api 文档的话，有个版本控制会比较方便。 |

# 文档软件的找寻之路

有时候，我们不知道我们想要什么。现在，即使知道想要的，现实可能也无法满足。

自建的 wordpress 服务，是底线。我只有找到更好的软件/服务，才有理由切换过去。

| 软件/服务 | 价格 | 备注 |
| --- | --- | --- |
| 语雀 | 公网访问的话，需要 99/年 | - 尝试了下，确实可以公网访问。  
- 但是，不支持被搜索引擎抓取。(测试方法：site:yuque.com)  
- 充值后，没有退款入口，哈哈  
- 语雀不适合写博客，但是日常使用还是非常方便的。而且，它的价格便宜，也适合作为公司内部的文档平台。  
- 背靠阿里，服务还是有一定保障的。 |
| confluence cloud | 公网访问的话，需要 6.7刀/月 | - 可以公网访问  
- 但是它的 SEO 非常糟糕，我的服务上线了20多天，使用site 方式，还是访问不到。而且，不支持，将自己的空间，添加到 google search console 中：[Add Confluence\[on-demand\] to my account Google Sea…](https://community.atlassian.com/forums/Confluence-questions/Add-Confluence-on-demand-to-my-account-Google-Search-Console/qaq-p/711462)  
- 国内访问会比较慢。价格也比语雀高。  
- 背后的公司在纳斯达克100里面，服务还是有保障的。 |

得，最后还是使用的 wordpress。目前，它大体也够用了。
