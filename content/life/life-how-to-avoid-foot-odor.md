# 前言

夏天的脚容易臭。

我们得先明白脚臭产生的原因。然后”对症下药“，有理有据的解决问题。

# 脚臭的根本原因

来源链接：[脚气＝脚臭？这个味道真的很上头，建议远离！_广东省疾病预防控制中心网站](https://cdcp.gd.gov.cn/zzzq/jkyw/content/post_4254911.html) 、[脚臭是脚气吗？怎么去除脚臭？实用的知识来了_澎湃号·湃客_澎湃新闻-The Paper](https://www.thepaper.cn/newsDetail_forward_14906065)

> 脚臭味并不是汗臭味。脚臭的罪魁祸首是细菌。
> 
> 
> 
> 
> 
> 人的脚掌上遍布有超25万个汗腺，每平方厘米有600多个汗腺，每天能分泌几十甚至数百毫升的汗液，是身体其他部位的2~4倍。
> 
> 
> 
> 
> 
> 汗液里除含水分、盐分外，还含有乳酸及尿素。只是乳酸和尿素本身也没什么味，但人的皮肤表面还有很多的细菌。
> 
> 
> 
> 
> 
> 科学家发现，对脚部气味影响最大的是寄生在我们皮肤上的葡萄球菌，它会产生一种叫做异戊酸的化学物质，异戊酸会令脚部发出干酪气味以及变质的醋酸气味。

**所以，脚臭的根本原因是，细菌分解脚汗中的物质，产生了不好闻的气味**。

# 脚臭的直接原因

脚臭的根本原因是微生物层面的，人眼直接看不到，容易被忽略。

脚臭的直接原因容易看到。下面我们来看看有哪些常见的直接原因：

- 鞋子本身不透气，脚部排汗增加。
- 鞋子没有经常晒太阳和清洗，细菌累积。
- 袜子不吸汗透气，汗液被留在了鞋子里。
- 袜子没有日日更换，吸汗性变差，细菌累积。
- 没有每天洗脚的习惯，细菌累积。
- 雨天潮湿的鞋子，没有及时清洗，导致的细菌增加。
- 天气炎热，脚步的排汗增加。
- 等等

上面罗列的这些原因，最终的造成的结果都是，细菌在脚步大量繁殖，分解营养物质，产生气味。

# 脚臭的解决

针对上面的直接原因，可以尝试下面的解决方法。

- 购买透气的鞋。200元左右的运动鞋，可以足够日常使用了。
- 购买透气的袜子。80%棉，20%锦纶/氨纶，这样的材质的袜子可以保证吸汗和耐用了。
- 鞋子经常晒，袜子天天换。
- 雨天潮湿的鞋子，要及时清洗。
- 上班路上穿运动鞋，到了工位，方便的话可以换拖鞋。
- 天气炎热，方便的话可以穿凉鞋。
- 使用银离子鞋袜除臭喷雾。银离子有杀菌作用。(或许应该考虑银离子通过皮肤进入人体。但是它相较于日常饮食中的富集作用，孰高孰低，不甚清楚。)
- 等等。

# 最后

如果遇到的所有问题，都能像脚臭一样容易解决，该多好啊。

但是，即使脚臭这样简单的问题，可能也并不容易”解决“。主要是因为物质和知识上的贫穷。

- 也许一些中年人并不舍得购买200元的运动鞋，他们节省习惯了，可能会偏向购买一些“假冒伪劣”，但似乎够用的产品。
- 也许一些中年人，青年人不善于从网络上搜寻答案。对于脚臭这样的小问题，也感觉没有必要去医院，采用一些无甚作用的民间偏方。
- 也许一些中年人，青年人，他们租的房子，出于经济原因，选择了没有没有阳光直射的出租屋。从而，无法给鞋子晒晒太阳。
- 也许一些中年人，青年人，他们在工厂上班，工厂安全规范的要求，无法在工作的时候换用拖鞋，或者穿凉鞋。
- 等等。

最后，脚臭是一个小问题，无关痛痒的小问题。相较于很多问题而言，它不值一提。
