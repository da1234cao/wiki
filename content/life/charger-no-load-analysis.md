## 前言

充电器空载的定义：手机、电脑充电器插在插座上但不接设备。

在家的时候，老爸会说空电器不能空载，要随手拔掉。在公司的时候，公司规定，上下班期间充电器禁止空载，被逮到罚款 200 元。

那充电器真的不应该空载吗？

## 禁止充电器空载的几个理由

禁止充电器空载的几个理由：
- 即使充电器处于空载状态，也耗电。
- 加速了充电器的老化。
- 违规充电器空载，可能带来安全隐患。

下面对着几个理由，逐一分析。

### 空载充电器的耗电情况

空载充电器确实会耗电。大概是，充电器里面的电阻电容会消耗一些电。

网上有人测过：
- [【闲谭】手机充电器一直插在电源插座上，一天用掉多少电？|电池|适配器\_网易订阅](https://www.163.com/dy/article/J579ATH30552N4FE.html)
- [充电器在不充电时，插在插座上会耗电吗？为什么？ - 知乎](https://www.zhihu.com/question/9860345756)

| 充电器类型       | 大约的空载功率 |
| ---------------- | -------------- |
| 手机充电器       | 0.271W         |
| 相机充电器       | 0.318W         |
| 笔记本电脑充电器 | 0.488W         |

其实，空载功耗有国家标准明的，核心标准是 GB 20943 系列。

现行有效的 [GB 20943-2013《单路输出式交流-直流和交流-交流外部电源能效限定值及节能评价值》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=73B6BEDF79049F8000906E7BEBA6A0FC) 第 4.2 节规定了空载状态下的最大有功功率限值。

新版 [GB 20943-2025《交流-直流和交流-交流电源能效限定值及能效等级》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=8105E9E58B8B8BDB5DF9D96119B1C60A) 已于 2025-01-24 发布，2027-02-01 实施，适用于额定输出功率不大于 500W 的外部电源（手机、笔记本充电器等）。标准明确定义空载状态为"产品输入端连接电网、输出端不连接负载"，能效分 3 级，3 级为市场准入底线：

| 能效等级       | 空载最大有功功率                          |
| -------------- | ----------------------------------------- |
| 1 级           | ≤0.05W（低电压单路输出；大功率段 0.075W） |
| 2 级           | 0.075W 起                                 |
| 3 级（准入线） | 0.1W ~ 0.5W（按功率段划分）               |

### 充电器的老化加速

没有数值做支撑。

充电器的老化因素有：
- 温度：电解电容对温度极其敏感：温度每升高10°C，电解电容寿命大致减半
- 电气应力：长期满负荷或超负荷工作，插拔瞬间会产生浪涌电流和电压冲击，市电电压不稳/电网波动，持续通电
- 元件本身的物理老化：电解电容干涸，焊点老化/开裂，绝缘材料老化

从上面的情况来看，充电器空载和插拔瞬间的冲击，谁带来的老化更大，也说不准。

所以，认为这个观点不成立，至少没有数据支撑。

### 违规充电器空载，可能带来安全隐患

这个观点，有案例，但是没有统计数据支撑。

真实事故案例（起火源头均为长期空载通电的充电器/数据线，且多为劣质、非原装、老化产品）：

- 贵州遵义（2025-04-12）：全屋烧毁，殃及两户邻居，损失超 50 万元（[一家人出门没拔充电器家里被烧光！当事人：无家可归，还要承担楼下住户的损失](https://m.gmw.cn/2025-04/18/content_1304017870.htm)）
- 福建莆田（2026-01-07）：非原装充电器通电三四天，卧室几乎烧空（[2天2起！房子变废墟，这种充电器可致命！](https://m.huanqiu.com/article/4Ptf4vYi7sy)）

## 个人观点

1. 单个充电器空载一年的电费就 1~3 块钱。家里插 5 个充电器也就十几元。电费这点损耗基本可以忽略
2. 主要考虑的是安全问题。使用正规厂家的充电器几乎不会出问题。毕竟，家里的空调和电视，可能是常年通电。它们的危险系数，应该是比空载的充电器要高的。
3. 充电器老化这种事，更没有数据支撑。就算老化加速了那么一点点，又怎么样。充电器肯定比那些被充电的手机电脑耐用。老化这种事情，完全不用考虑。
4. 小员工，在公司要服从规定，毕竟要融入环境的嘛。但是，在自己的屋里，充电器是否空载，随缘。
